# Imposter

En mobilanpassad webbapp för Imposter, byggd för att kunna köras direkt från en GitHub Pages-länk och sparas på telefonens hemskärm.

## Kör lokalt

Öppna `index.html` direkt i webbläsaren.

## Publicera

1. Lägg upp repot på GitHub.
2. Aktivera GitHub Pages för branchen `master` eller `main`.
3. Öppna GitHub Pages-länken i mobilen.
4. Välj "Lägg till på hemskärmen" i webbläsaren.

## Första versionen

- Välj speltyp.
- Välj en eller flera ordkategorier.
- Välj antal spelare och skriv in namn.
- Välj antal imposters.
- Skicka runt en telefon och låt varje spelare trycka för att vända sitt kort.
- Starta ny runda med samma inställningar.
